Positioning

Normal Flow is the default way that an html code is organized before any changes are applied through css

Float changes the floating position of text, and it organizes based off of that. Clear is done by writing a class and clear: both; as a parameter.

Position relative just shoves things around, but position absolute you can control exactly where you want it to go, and fixed gets put exactly on the window, so even if you scroll it remains permenant.
