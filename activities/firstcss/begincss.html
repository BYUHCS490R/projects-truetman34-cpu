Beginning CSS

HTML Attributes, original HTML sites, allows sites from the 1990s able to be viewed.
Inline CSS: uses HTML style tags, allowing for style changes. No using for class!!
Embedded CSS: put style tags in header, then select using selector p or other tags
External CSS is used in a different file all together.

Due to priorities, external CSS takes lowest, and to let the graphic designers edit and do it properly its important not to use inbedded or inline. That and it takes a long time to apply styles to every page, where external css just links to all and modifies all pages.

The selector is used before the curly brackets to define what the css code is targeting. (Main p, p, Header, h1)
