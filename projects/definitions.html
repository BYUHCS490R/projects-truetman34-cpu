Web

Difference between internet and web

ASCII and Unicode

Labeled by charset, ASCII - older 7 bit version, only american english characters. UTF - Chracters of almost every language in the world.

UTF-8

The percived dominant character system, characters from 1-4 bytes, from english to japanese. Depending on character changes bytes used.

URL

Standing for Uniform resource locator, refers to a web address. Helps locate certain resources on the web. The complete domain name.

Domain Name

website names like Google.com, which then is translated through a DNS to a IP address.

HTTP

The communication procedures how the web communicates, HTTP being a public version of HTTPS.

HTTPS

The secure version of HTTP, which encrypts information as it goes throughout the web.

IP Address

An address that identifies electronic devices, allowing for communication and data transfer.

DNS

DNS is what changes a domain name for humans to an IP address for computers to read.

XML, XHTML, HTML, HTML5

XML: A data exchange language, not displaying data but describing, storing, and transporting it.

XHTML: An updated version of HTML 4.01, combining XML tools and standard HTML system.

HTML: Standard language for displaying coded files into web pages.

HTMP5: The current standard for displaying web content, appearing to be the most flexible and modern version of HTML.
